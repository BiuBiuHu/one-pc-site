## 安排日历是什么

Anpai.Life 的定位是**个人节奏系统**：把目标、日程、复盘和 Agent 放在同一条连续工作流里。不是再做一个清单 App，也不是在日历旁边挂几个插件。

日常用法可以收成四步：

1. 在月 / 周 / 日之间切换，把时间看清楚
2. 用年度目标和里程碑，把方向定下来
3. 做一次周复盘，让 AI 洞察变成下一周的安排
4. 跟 Agent 说话：自然语言排期、拆目标、看这一周

PC 上是一张完整工作台（Web / macOS），手机上接住当下，两边同步。想先上手，打开 [web.anpai.life](https://web.anpai.life/) 进日历首页；首次新增或编辑时，产品会按需拉起登录。

## 月 / 周 / 日：日历是主界面

安排日历的家是日历，不是清单旁边的一层视图。

- **月视图**：看整块疏密。哪几周已经被会议和杂事填满，哪几天还空着，一眼能扫完。
- **周视图**：看这一周真正占住的时间。大方向要落进具体的上午、下午，而不是只停在「本周要做」。
- **日视图**：把今天收成几件真正能完成的事。从年度目标到「今天这一格」，最后落在这里。

三个视图切的是同一套日程。用法通常是：月初用月历排疏密，周一用周视图排块，当天用日视图执行。产品页上的那句话就是这个意思——**不是把事情塞进日历，而是让日历服务于你的方向。**

## 图历与历书：给每一天一点颜色

月 / 周 / 日把时间看清楚。打开「今天」的时候，安排日历还多一层——**图历**。它不是另一张待办，是每天一张 AI 生成的海报：公历、农历、干支、节气写在上面，再配上当日的宜忌和一句引语。同一天可以换成「纳瓦尔宝典」或「毛选」这一类风格，气质不同，日子还是这一天。

同一天也有宽幅：

![同一天的宽幅图历海报](/images/anpai-vs-ticktick-free/tuli-poster-medium.png)

入口很轻：日历顶部点「图片」，或直接打开 [web.anpai.life/calendar-image](https://web.anpai.life/calendar-image)。不必先排完整周，也不必先写年度目标。先看今天长什么样，就够判断这层东西顺不顺手。

同一条时间线上还有**历书**这一栏。图历负责「今天的颜色」；历书把宜忌收成可以照着做的宜 / 忌，再标出几段专注窗口。一边是海报，一边是今天还能怎么过。

## 目标与里程碑：方向不只写在年初

目标在安排日历里不是一篇单独的笔记，而是给日历格子上下文的那一层。

你可以写下**年度目标**，以及希望为它投入的时间；再给目标加上**里程碑**，并记下投入时长，让进度有迹可循。做日程的时候，看见的不只是「下午写方案」，还有「这件事为什么在今年的方向上」。

适合放进来的，是那种跨周、跨月、需要反复回到日历里的事：写完一版产品、跑完一轮训练、把一个副业推过某个节点。一次性的杂事不必先升级成目标；目标存在，是为了让月 / 周 / 日的安排有据可依。

## 周复盘 + AI 洞察：复盘是下一周的起点

一周过完，安排日历要你回看，而不是只往前勾。

复盘看的是**时间和精力**花在了哪里。AI 洞察会标出时间分配上真正重要的变化——哪一类安排变多了，哪一类目标这周几乎没被碰到——再把这些观察送回下一周的安排。所以复盘不是写一篇总结存档，而是闭环的第三步：看清这一周，才能排下一周。

和「把所有任务标完成」不一样。列表可以全绿，一周仍然看不清。复盘要回答的是：这周的日子，有没有对着目标走。

## Anpai Agent：结合你的目标、安排和复盘

Agent 挂在这条闭环上，不是一个会聊天的空框。它会结合你的**目标、已有安排和复盘记录**来工作。产品页写明了边界：**不替你做决定**；它把模糊的想法收成清晰、可执行的下一步，选择权留在你手里。

现在能明确说的几件事：

- **自然语言排期**：一句话说时间和事，落到月 / 周 / 日里。中文时间怎么听、何时该追问，本站写过 [中文时间解析的坑](/blog/chinese-time-parsing/)。
- **目标拆解**：把「这周做完产品方案」收成可以放进日历的几步，而不是停在一句空目标。
- **周洞察**：跟复盘连在一起，看这一周的分配，再建议下一周。
- **上下文**：建议会带着你已经写下的目标和已经占住的日程，而不是凭空生成一张待办。

产品页上有一个具体的来回：你说「我想在这周完成产品方案，但每天都被零碎事情打断」；Agent 看着已有安排，建议把方案拆成几个专注区块，并先锁定其中一块时间。你仍然可以改、可以不采纳。它是日历和目标旁边的助手，不是另一套清单系统。

## PC 工作台和手机同步

同一套节奏有两个入口，登录同一个账号后，**日程、目标、复盘和偏好**会一起走。

- **PC（Web / macOS）**：月 / 周 / 日、年度目标、复盘中心和 Agent 在一张工作台上。适合坐下来排一周、写目标、做复盘。Web 入口就是 [web.anpai.life](https://web.anpai.life/)。
- **移动端**：快速记下日程、看目标进度、接收 Agent 建议。适合路上接住一件事，不把计划只留在桌面上。

清单应用真正难的往往是同步，不是页面。如果想看这类产品为什么要本地优先、版本号和软删除，可以读 [清单应用的同步架构](/blog/todo-app-sync-01/)。

## 从 web.anpai.life 开始

软性的下一步就这一件：打开 [web.anpai.life](https://web.anpai.life/)，先看自己的月 / 周 / 日。首次新增或编辑内容时，再登录。想先读产品故事，去 [www.anpai.life](https://www.anpai.life/)。

不必先从别的工具「搬家」。加一个目标、放进一件今天的事、看一张图历，或跟 Agent 说一句要安排的话，就够判断这套闭环顺不顺手。
