> 你好，欢迎来到《从零手搓 AI Agent》。这篇是开篇词，说说这个专栏从哪来、想到哪去、怎么读。

## 这个专栏从哪来

2026 年春天，我开始认真回答一个问题：

> "人人都在说 Agent，可把框架拆开，里面到底是什么？"

于是有了这份学习笔记的开头——一个只能"一次问答就退出"的 CLI 小程序，和一道最朴素的问题：**LLM 为什么记不住上一句话？**

从这个问题出发，一路滚到了多轮对话、流式输出、工具调用，又为了搞懂 SDK 的封装，把请求一层层拆到裸的 `fetch` 与 SSE 字节流；为了让它能在生产环境活下来，补上了上下文管理、记忆、安全沙箱、可观测、成本控制、断点续传；再往后，是多 Agent 协作、消息队列、远程网关，一直到 ACP / A2A 这样的 Agent 互操作协议。

前前后后 54 篇笔记，每篇都带着可运行的代码。现在我把它们整理成这个专栏——**这不是"我学会了 AI"的故事，而是一份"我把它手搓了一遍"的工程记录。**

## 这个专栏怎么读

每篇文章的结构很稳定：

1. **核心问题**——一句话说清这篇要解决什么
2. **原理拆解**——把黑盒打开，讲清楚机制
3. **代码实现**——能跑的代码，而非伪代码
4. **踩坑记录**——实际动手时真实的坑
5. **知识点总结**——收口回顾

推荐三条路线：

- **速通**（已有基础）：卷一基础四件套 → 卷二手写底层 → RAG / 结构化输出 → 生产级质量保障
- **系统**（从零开始）：按卷一到卷八顺序，别跳
- **面试冲刺**：第七课手写 Loop → Hooks 与 Human-in-the-Loop → 幻觉防治 / 成本 / 可观测 / 断点续传 → 附录七题速答卡

## 三个贯穿始终的原则

**一、每篇回答一个核心问题。** 学完能答上来，才算真的会；答不上来就回去再读。

**二、先会用 SDK，再亲手"去魔法"。** 框架帮你跳过的地方，往往就是生产事故埋伏的地方。所以专栏专门用一卷手写底层——不是炫技，是为了让你真正拥有它。

**三、每课都有可运行的代码产出。** 光看不练没有效果，这是技术学习的铁律。

## 适合谁

- 会 TypeScript / Node.js，想真正搞懂 Agent 内部原理的工程师
- 被 Agent 框架"包"住，想 strip 掉魔法看底层的开发者
- 正在把 Agent 从 demo 推向生产的构建者

不适合谁：想找"一句提示词让 AI 变强"的速成秘籍——这里没有魔法，只有把魔法拆开的过程。
